Getting started

첫 화면부터 차근차근.

Studio를 설치하고, 사용할 화면을 고른 다음,
간단한 버튼 하나부터 실행해 보세요.

01. Windows에 Studio 설치

  1. 공식 Windows 설치파일을 받습니다. Windows 10 1809 이상 또는 Windows 11의 x64 환경이 필요합니다.
  2. 설치파일을 실행하고 이용약관과 개인정보·통신 안내를 확인합니다. 기본 설치 위치는 %LOCALAPPDATA%\Programs\DeskDeck입니다.
  3. 화면 표시용 Microsoft WebView2가 없으면 설치 과정에서 내려받습니다. 이 경우 인터넷 연결이 필요합니다.
  4. 설치 후 DeskDeck Studio를 실행합니다. 첫 사용은 별도 장치 없이 가상창으로 시작하셔도 됩니다.

게시자를 확인할 수 없다는 안내가 나타날 수 있습니다. 이번 Windows 배포본에는 Authenticode 코드 서명이 없습니다. 공식 저장소와 파일 이름, 릴리스의 SHA-256을 대조해 주세요. 보안 프로그램이나 조직의 설치 제한을 해제할 필요는 없습니다. 설치가 차단되면 관리자에게 문의해 주세요.

일반 설치에는 관리자 권한이 필요하지 않습니다. 자동 실행은 Studio의 일반 설정에서 바꿀 수 있습니다.

02. 기기 없이 가상 DeskDeck 사용

  1. Studio의 일반 설정에서 기기가 없을 때 가상 DeskDeck을 표시하는 옵션을 켭니다.
  2. 별도로 뜨는 DeskDeck 창의 버튼을 마우스로 클릭합니다. 터치 모니터라면 직접 누를 수 있습니다.
  3. 창을 원하는 모니터로 옮기고 가장자리를 잡아 크기를 조절합니다. 창 크기와 위치는 저장됩니다.
  4. 가상창 크기를 최근 연결된 기기 크기에 맞추는 옵션도 선택할 수 있습니다.

작은 터치 모니터나 남는 보조 모니터에 배치하면 작업용 컨트롤 패널로 사용할 수 있습니다. 별도 하드웨어 구매나 휴대폰 앱 설치가 필요하지 않습니다.

03. Android 휴대폰 연결

Android 8.0 이상을 지원합니다. 먼저 휴대폰과 PC를 같은 신뢰할 수 있는 로컬 네트워크에 연결해 주세요. PC는 유선 LAN, 휴대폰은 Wi-Fi로 연결되어 있어도 서로 통신할 수 있으면 됩니다.

앱 준비

  1. Studio의 기기 → Android 휴대폰 연결을 엽니다. 앱 준비 단계에서 설치 여부를 선택합니다.
  2. 아직 설치하지 않았다면 Studio가 보여주는 QR을 휴대폰으로 스캔하고 브라우저에서 APK를 받습니다.
  3. Android가 요청하면 해당 브라우저의 ‘알 수 없는 앱 설치’를 허용하고 설치를 승인합니다. 설치 후 그 권한은 다시 꺼도 됩니다. 조직에서 금지한 설치 정책은 우회하지 마세요.
  4. 휴대폰에서 DeskDeck을 실행하고 Studio의 ‘설치 완료·다음’ 안내를 따릅니다.

Wi-Fi로 연결

  1. Studio에서 Wi-Fi 연결을 선택하고, 휴대폰에서도 Wi-Fi 접속을 선택합니다.
  2. PC 찾기로 내 PC를 고르고 Studio에 표시되는 최초 6자리 번호를 입력합니다.
  3. 버튼 화면이 나타나면 연결이 완료됩니다. 이후에는 저장한 등록 정보로 다시 연결합니다.

USB 케이블로 연결

  1. 데이터 전송을 지원하는 USB 케이블로 잠금 해제한 휴대폰을 PC에 연결합니다.
  2. 휴대폰 DeskDeck의 USB 접속 탭을 선택하고, Studio 연결 안내에서 USB 케이블을 선택합니다.
  3. 필요한 경우 안내에 따라 선택적 UsbDk 드라이버를 별도로 설치합니다. 관리자 권한이 필요한 시스템 드라이버이며, 이번 설치파일에 포함되거나 자동 설치되지 않습니다.
  4. 휴대폰의 USB 액세서리 사용 요청을 승인합니다. USB AOA 연결에는 최초 Wi-Fi 연결용 6자리 번호가 필요하지 않습니다.

일반 Wi-Fi·AOA 연결에 USB 디버깅은 필요하지 않습니다. 케이블·휴대폰·PC USB 환경에 따라 AOA 호환성은 다를 수 있습니다.

앱 업데이트와 화면 설정

버튼 화면 하단 가운데의 작은 톱니바퀴에서 앱 설정을 엽니다. 화면 밝기·대기 시간, 도움말, 앱 버전, 앱 업데이트를 확인할 수 있습니다. 앱 업데이트는 연결된 Studio의 배포본을 확인하고 브라우저 설치 안내로 이어집니다. 전체화면 위젯에서는 버튼 화면으로 돌아온 뒤 설정을 열어 주세요.

04. ESP32 보드 연결

현재 지원 보드는 JC3248W535입니다. 모든 ESP32 화면에 동일한 펌웨어를 설치할 수 있는 것은 아닙니다.

  1. 데이터 USB 케이블로 보드를 PC에 연결합니다.
  2. Studio의 기기 → ESP32 보드 연결에서 JC3248W535를 고르고 연결 안내를 따릅니다.
  3. 처음 사용하는 보드라면 기존 펌웨어를 백업할지 선택한 후 DeskDeck 펌웨어를 설치합니다. 보드와 포트를 확인하고 기록 중에는 케이블을 분리하지 마세요.
  4. USB로 버튼 화면과 입력이 작동하는지 확인합니다.
  5. 무선을 사용하려면 USB 연결 상태에서 Wi-Fi 설정 안내를 진행합니다. 설정 후 같은 네트워크에서 USB 데이터 연결 없이 사용할 수 있으며, 보드 전원은 계속 필요합니다.

전체 플래시 백업에는 Wi-Fi 비밀번호 등이 들어갈 수 있습니다. 공개 이슈나 문의 메일에 백업 파일을 첨부하지 마세요. 현재 동봉 펌웨어는 0.8.1입니다.

05. 버튼과 매크로 만들기

  1. Studio 미리보기에서 바꿀 버튼을 선택합니다.
  2. 이름과 동작을 정합니다. 설치된 앱에서 고르거나 앱 실행 경로, 단축키, 시스템 정보 등을 선택할 수 있습니다.
  3. 기본 아이콘이나 사용자 아이콘을 선택합니다.
  4. 저장하고 보드에 적용을 누릅니다. 이 버튼은 연결된 휴대폰과 가상창에도 설정을 적용합니다.

버튼 정리와 이미지

미리보기에서 오른쪽 클릭하면 복사·잘라내기·붙여넣기, 왼쪽/오른쪽 삽입, 삭제, 초기화를 사용할 수 있습니다. 삽입·삭제는 페이지를 넘어 버튼을 순서대로 이동하며 M 페이지는 마지막에 유지됩니다. 초기화는 내용을 지우고 자리를 유지합니다.

동작 목록의 빈 버튼에는 아이콘 라이브러리에서 사용자 이미지를 넣을 수 있습니다. 이미지는 비율을 유지해 표시하며 터치해도 실행하지 않습니다. + 추가 슬롯을 누르면 Studio의 편집 화면이 열립니다. 이미지 변경 후에는 저장하고 보드에 적용을 누르세요.

버튼 조합 매크로

버튼 동작뿐 아니라 단축키, 문자열, 대기를 순서대로 넣을 수 있습니다. 종류를 선택하고 내용을 입력한 뒤 ‘선택 아래에 추가’를 누릅니다. 대기는 초 단위이며 소수도 사용할 수 있습니다. Tab과 Enter는 단축키 입력으로 넣을 수 있고, 문자열 뒤에 Enter를 보내는 옵션도 있습니다.

매크로 편집창의 ‘확인’은 편집 내용을 버튼 설정으로 돌려줍니다. 마지막으로 Studio에서 ‘저장하고 보드에 적용’을 눌러야 저장됩니다. 실행 중인 매크로는 하단 또는 트레이에서 중단할 수 있습니다.

문자열은 Windows 사용자 계정에 연결해 암호화 저장하지만 실행 시 실제 입력으로 전달됩니다. 먼저 안전한 테스트 창에서 확인하고, 다른 창에 비밀번호나 문장이 입력되지 않도록 주의해 주세요. ‘암호’ 체크는 목록에서 문자열을 가리는 표시 옵션입니다.

페이지 관리

페이지 추가·초기화·순서 관리를 사용할 수 있습니다. 화면이 커지면 일반 버튼은 저장된 순서대로 재배치되고 페이지 수가 줄어들 수 있습니다. 미디어 M 페이지는 마지막에 유지됩니다. 좌우 끝 영역이나 스와이프로 순환 이동합니다.

06. 전체화면 위젯

시계, Neko, 미디어 등 기본 위젯을 선택하세요. 위젯 관리에서 사용 여부를 정하고 드래그로 순서를 바꿀 수 있습니다. 일정 시간 입력이 없을 때 전환하도록 하거나 직접 열 수 있습니다.

화면 좌우 끝을 누르거나 스와이프하면 다른 위젯으로 이동합니다. 일반 시계·Neko는 화면 터치로 버튼 화면에 돌아오며, 조작 위젯은 표시된 복귀 동작을 사용합니다. 비율을 유지해 표시하고 주변 여백은 위젯 배경에 맞춥니다. 장시간 같은 위치에 고정되지 않도록 미세 이동을 사용합니다.

Android의 대기 밝기는 휴대폰 앱에서 따로 정합니다. Windows 모니터가 꺼진 상태의 화면 제어와, PC 자체가 절전한 상태는 다릅니다. PC가 완전히 절전하면 정상 통신을 계속할 수 없습니다.

07. 연결이 잘되지 않을 때

PC 찾기나 QR 페이지가 열리지 않아요.

PC와 휴대폰이 같은 로컬 네트워크인지, 게스트 Wi-Fi에서 기기 간 통신을 막고 있지는 않은지 확인하세요. Studio의 문제 해결 안내에서 필요한 방화벽 접근만 허용합니다. 다운로드 중에는 설치 안내 창을 열어 두세요.

USB 충전은 되는데 연결되지 않아요.

충전 전용 케이블 대신 데이터 케이블을 사용해 주세요. Android 앱의 USB 접속 선택, 액세서리 승인, AOA 드라이버 상태를 확인합니다. ESP32는 Studio에 표시되는 포트와 지원 보드 종류를 확인하세요.

창을 닫아도 Studio가 실행 중인가요?

Studio는 트레이에서 계속 동작할 수 있습니다. 완전히 종료하려면 트레이 메뉴의 종료를 사용하세요. 다시 설정을 열려면 트레이 아이콘을 클릭합니다.

Android 앱 설치가 거부돼요.

Studio의 QR 안내로 브라우저에서 APK를 다시 받아 보세요. 이전에 다른 서명으로 빌드된 앱은 바로 덮어쓸 수 없습니다. 기존 앱을 삭제하기 전에 연결 정보 등 필요한 설정을 확인하세요. 보안 정책 차단은 해당 관리자에게 문의합니다.

오류를 알려 주세요

GitHub 이슈 또는 deskdeck.app@gmail.com으로 버전, 연결 방식, 재현 단계와 오류 문구를 보내 주세요. 비밀번호·개인 설정·기기 전체 백업은 보내지 마세요.

08. 종료와 제거

트레이 메뉴에서 Studio를 종료한 뒤 Windows의 설치된 앱에서 DeskDeck을 제거합니다. 설정은 %LOCALAPPDATA%\DeskDeck에 남을 수 있습니다. 필요한 설정을 보관한 후 이 폴더와 직접 지정한 백업 폴더만 확인해 삭제하세요.

선택적으로 설치한 UsbDk는 별도 프로그램이므로 필요 없을 때 별도로 제거합니다. Android 앱 데이터와 ESP32 등록 정보의 삭제는 각 기기의 안내를 따릅니다.
