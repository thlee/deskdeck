再利用旧 Android 需要什么？

  • Windows PC： 在 Windows 10 1809+ 或 Windows 11 x64 上运行 Studio。
  • 手机或平板： 支持 Android 5.0+，手机和平板使用同一个应用。
  • 连接： 使用同一局域网的 Wi-Fi 或 USB 数据线，PC 可以连接有线以太网。

例如 Galaxy S8（Android 9）可作为紧凑快捷面板，LG G Pad 8.0（Android 5.0.2）可提供较大的按钮和小组件屏幕。USB 兼容性取决于设备和线缆。

把旧平板或手机变成宏面板

  1. 在 PC 上安装 Baroham Studio

    下载： Windows 安装程序 并打开 Studio。

  2. 在 Android 设备上安装 Baroham

    在 Studio 的以下菜单中启动 Android 手机连接指南： 设备 。将 PC 与手机置于同一网络，扫描二维码在浏览器下载应用，并按说明安装。

  3. 通过 Wi-Fi 或 USB 连接

    可先使用同一网络的 Wi-Fi，在手机输入 Studio 显示的六位代码。USB 请参考下方连接指南。

  4. 创建按钮

    在 Studio 预览中选择按钮，指定应用、快捷键、文件、文件夹、URL 或宏。 保存并应用 后，连接手机的画面也会更新。

应该使用 Wi-Fi 还是 USB？

Wi-Fi · 轻松入门

手机与 PC 使用同一局域网，无需 SIM 卡或移动套餐。保存配对信息后即可再次连接。

USB · 没有 Wi-Fi 时

应用安装后，USB AOA 不需要共享 Wi-Fi。需要数据线和手机配件授权。Windows 可能需单独安装 UsbDk 驱动，正常使用无需 USB 调试。

旧设备 USB 不稳定时可先试 Wi-Fi。某些平板更新应用后需要重新插拔线缆。 排查连接问题 →

旧手机再利用常见问题

没有 SIM 卡的手机可以用吗？

可以。Baroham 通过 Wi-Fi 或 USB 连接 PC，不需要 SIM 卡、电话号码或移动套餐。

厂商停止更新的平板可以使用吗？

可使用能安装并运行应用的 Android 5.0+ 设备。USB 兼容性各异，可先从 Wi-Fi 开始。

可以作为免费的 Stream Deck 替代方案吗？

应用启动、快捷键、宏和媒体控制都可放在触控按钮上。利用已有手机或平板构建控制面板，无需专用键盘。

PC 关机后还能使用吗？

按钮屏幕和小组件连接 PC 上运行的 Studio。PC 关机或完全睡眠时，无法继续正常通信与控制。

没有互联网可以使用吗？

安装配置后，可通过 USB 或允许设备互通的局域网连接。本地应用启动和快捷键无需互联网；网站、新闻、天气等在线功能需要。

没有手机可以开始吗？

可以。用鼠标操作虚拟 Baroham，或将其放在小型触摸显示器、副屏上。 了解虚拟 Baroham →
