DeskDeck 공개 무료 평가판 이용약관
버전: 2026-10-11-public / 제공자: 이태호 / 문의: deskdeck.app@gmail.com

1. 무료 사용권
누구나 이 DeskDeck 공개 무료 평가판을 본인이 관리하거나 사용 권한을 가진 Windows PC와 지원 기기에 설치하여 개인 용도 및 업무 환경에서 무료로 사용할 수 있습니다. 이 버전의 사용권은 비독점적이며 기간 제한이 없습니다. 결제·후원·구독·계정 등록은 요구하지 않으며 자동 결제나 유료판 자동 전환은 없습니다. 직장 내 사용은 해당 조직의 보안·소프트웨어 사용 정책을 따라야 합니다.

2. 권리와 배포 범위
무료 공개는 저작권 양도나 Studio·Android 자체 소스의 오픈소스 공개를 뜻하지 않습니다. DeskDeck 자체 프로그램과 디자인의 권리는 이태호 또는 적법한 권리 승계인에게 있으며, 제3자 구성요소의 권리는 각 권리자에게 있습니다. 필요한 설치·백업 복사는 허용합니다. 공식 소개·다운로드 링크를 자유롭게 공유할 수 있습니다. DeskDeck 자체 프로그램의 재판매, 변조 배포, 별도 다운로드 미러 운영, 자체 코드의 수정·다른 제품 편입은 권리자의 별도 허락이 필요합니다. 이 제한은 법률이 허용하는 행위, 제3자 라이선스 또는 펌웨어 재링크 허가에 따른 권리를 제한하지 않습니다.

3. 외부 소프트웨어와 소스 제공
Microsoft 런타임·SDK, GPL/LGPL 및 기타 오픈소스에는 각각의 동봉 약관이 우선 적용됩니다. GPL/LGPL 구성요소의 사용·복사·수정·재배포 및 수정 사항 디버깅을 위한 역공학 권리를 이 평가판 약관으로 제한하지 않습니다. 대응 소스와 펌웨어 재링크 자료는 평가판과 함께 제공하는 소스 패키지에 포함합니다. 이 자료가 DeskDeck Studio 전체를 오픈소스로 전환하는 것은 아닙니다. 별도 프로세스로 실행되는 펌웨어 설치 어댑터는 그 폴더의 GPL-3.0-or-later 사용조건을 따릅니다. 소스 패키지가 빠졌거나 열리지 않으면 제공자에게 요청할 수 있습니다.

4. Microsoft 구성요소
Microsoft 구성요소는 DeskDeck의 일부로만 사용·배포하며 별도 상품으로 재판매하지 않습니다. 동봉된 Microsoft .NET Library, Windows SDK, WebView2 Runtime 및 Python Windows 배포본의 Microsoft 재배포 코드 조건에 정한 보호 조건을 준수해야 합니다. 관련 법률 또는 해당 오픈소스 라이선스가 허용하는 경우를 제외하고 기술적 제한의 우회, 역공학·디컴파일·분해, 저작권·상표 고지의 제거·변조, 불법적 사용을 허용하지 않습니다. Microsoft 코드는 Windows 운영체제·런타임·응용 플랫폼에서만 사용하며 악성·기만적인 프로그램에 포함하지 않습니다. Microsoft의 소프트웨어 소유권·보증 부인·책임 제한 및 수출 관련 조건은 동봉된 원문에 정한 범위에서 적용됩니다. DeskDeck은 Microsoft가 제작하거나 후원하는 제품이 아닙니다. 제3자 약관과 이 약관이 충돌하면 해당 구성요소에 대해서는 제3자 약관이 우선합니다.

5. 사용자 설정과 PC 제어
DeskDeck은 사용자가 지정한 앱 실행, 단축키, 문자열·매크로 입력 등을 수행합니다. 사용 권한이 있는 장비에서만 사용하고 회사 보안 정책을 준수해 주세요. 잘못된 대상 창에 문자열을 입력하지 않도록 대상과 매크로 내용을 확인해 주세요. 암호화된 매크로 저장은 비밀번호 관리자를 대체하지 않습니다. 펌웨어 설치·복구 전에는 안내에 따라 기기를 확인하고 필요한 백업을 보관해 주세요.

6. 개인정보와 외부 통신
별도 개인정보·통신 안내에 저장 위치, 기기 통신, 날씨 및 Microsoft 관련 통신을 설명합니다. 개인정보 안내를 확인하는 것은 선택 기능에 필요한 운영체제 권한을 포괄적으로 허용하거나 선택적 정보 전송에 자동 동의한다는 뜻이 아닙니다. 문의 메일과 오류 자료는 사용자가 직접 보낼 수 있으며 비밀번호·기기 전체 백업 등 민감한 내용을 보내지 마세요.

7. 평가판의 한계와 책임
평가판에는 오류와 기능 변경이 있을 수 있으며 무중단 동작, 특정 목적 적합성, 모든 기기·앱과의 호환성을 보장하지 않습니다. 제공자는 법령이 허용하는 범위에서 보증과 손해배상 책임을 제한합니다. 고의·중대한 과실에 대한 책임, 개인정보 관련 의무 또는 적용 법령상 배제할 수 없는 권리는 이 약관으로 제한하지 않습니다. 제3자 소프트웨어에는 각자의 보증·책임 조건이 적용됩니다.

8. 향후 버전·후원·운영 변경
제공자는 향후 새로운 버전·추가 기능·서비스를 별도 유료 조건으로 제공하거나 자발적 후원 방식을 도입할 수 있습니다. 이는 현재 후원을 받거나 유료 전환을 약속한다는 뜻이 아닙니다. 도입 시 적용 대상·가격·조건을 미리 안내하고 별도로 선택·동의하도록 하며, 이 버전에 이미 부여한 무료 사용권에 소급하여 요금을 부과하거나 유료 이용을 강제하지 않습니다. 향후 업데이트·신규 기능·유지보수·외부 서비스의 영구 무료 제공이나 지속 제공을 약속하지 않습니다.

9. 권리 이전
DeskDeck 자체 권리의 양도·사업 이전·운영자 변경이 있더라도 이미 적법하게 받은 이 버전의 무료 사용권과 제3자 라이선스상 권리는 유지됩니다. 양도 대상에는 양도인이 보유한 권리만 포함되며 제3자 오픈소스의 독점권을 주장하지 않습니다. 개인정보 이전이 필요한 경우 적용 법령상 고지·동의 등 절차를 별도로 따릅니다.

10. 종료·문의
사용자는 사용을 중단하고 앱을 제거할 수 있습니다. 제거 후 남는 개인 설정·백업의 삭제 방법은 개인정보 안내에 따릅니다. 중대한 약관 위반이 있는 경우 제공자가 시정 요청 후 해당 사용권을 종료할 수 있습니다. 제공자 문의: 이태호, deskdeck.app@gmail.com. 대한민국 법령 및 적용되는 강행 법규에 따라 해석하며 법정 관할과 소비자의 강행적 권리를 제한하지 않습니다.

A. HISTORY OF THE SOFTWARE
==========================

Python was created in the early 1990s by Guido van Rossum at Stichting
Mathematisch Centrum (CWI, see https://www.cwi.nl) in the Netherlands
as a successor of a language called ABC.  Guido remains Python's
principal author, although it includes many contributions from others.

In 1995, Guido continued his work on Python at the Corporation for
National Research Initiatives (CNRI, see https://www.cnri.reston.va.us)
in Reston, Virginia where he released several versions of the
software.

In May 2000, Guido and the Python core development team moved to
BeOpen.com to form the BeOpen PythonLabs team.  In October of the same
year, the PythonLabs team moved to Digital Creations, which became
Zope Corporation.  In 2001, the Python Software Foundation (PSF, see
https://www.python.org/psf/) was formed, a non-profit organization
created specifically to own Python-related Intellectual Property.
Zope Corporation was a sponsoring member of the PSF.

All Python releases are Open Source (see https://opensource.org for
the Open Source Definition).  Historically, most, but not all, Python
