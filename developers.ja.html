サンプルZIPを入手AIと作る

推奨：Windows Studio 0.9.42+ · macOS 0.9.40 build148+
任意インストール · オフライン例 · MITライセンス

クイックスタート画面に合わせた配置ファイル & コードAPIs & 実行環境AI向け開発手順検証 & 共有ウィジェットの配布と販売

クイックスタート

  1. サンプルZIPをダウンロードし、次の一覧にドロップします： 全画面 → ウィジェット管理。有効にして、順序と有効状態を保存してください。
  2. メッセージとテーマの変更は、 ウィジェット設定から行い、続いて 機器で今すぐ表示を選びます。機器または仮想全画面のカードをタップすると数値が増えます。
  3. ZIPを展開してmain.jsを編集します。新規ウィジェットには固有のid、更新には大きいversionを使います。ZIPにまとめるのは フォルダー内のファイルです。外側のフォルダーは含めず、再インポートしてください。
ウィジェットはPCのStudioで動作します。ESP32やAndroidにコードを別途インストールしません。プレビューでは数値は変わらず、メモリ上のカウントはStudio再起動でリセットされます。

画面に合わせた配置

既存のウィジェットは480×320のままです。viewport:1を要求する新しいJavaScriptウィジェットはapi.width、api.height、api.contentRectで配置し、同じ座標でタッチを受け取れます。

viewport:1に対応するWindows Studio 0.9.41 / macOS 0.9.40 build148以降が必要です。Mac/Windowsの仮想画面で利用でき、ESP32と現行Androidは480×320互換モードを維持します。転送画像の解像度を上げる機能ではありません。

レスポンシブ例のZIPを入手

ファイル & コード

manifest.json    # ID, version, permissions
main.js          # render(api)
settings.json    # message, theme
locales/         # ko, en, ja, zh-Hans
LICENSE.txt

このような小さなrender関数から始められます。インストール可能な例にはタッチ重複防止、設定、翻訳も含まれます。

const widget = {
  render(api) {
    api.useThemeBackground?.();
    const c = api.canvas;
    c.fillStyle = '#86E9C6';
    c.font = '24px sans-serif';
    c.textAlign = 'center';
    c.fillText(api.settings.message, 240, 160);
  }
};

資料は展開して読み、編集してください。Studioにインポートするのは別のサンプルZIPです。

APIs & 実行環境

描画 & タッチ

従来の480×320または選択式レスポンシブ座標、描画命令700個以内、状態32KiB以内。タッチにはpackageVersion 3、api.inputs、api.active、sequenceの重複防止を使います。戻る・左右移動はStudioが管理します。

設定 & 画像

settings.jsonで文字列、スイッチ、選択肢を定義します。テーマ背景、翻訳、制限内のJPEG背景と静的WebPスプライトを利用できます。

ネットワーク & 安全性

必要なHTTPSホストのみを宣言し、api.httpJsonのキャッシュを使います。Studioのインターネット設定に従います。ファイル変更、任意コマンド、カメラ、マイクのAPIはありません。

共通ホストサービス

システム・メディア・天気の読み取り専用スナップショットと宣言型ニュース・写真サービスには明示的な契約と権限が必要です。任意のJavaScript関数ではありません。

APIガイドを読む

JavaScriptは同期render(api)で実行されます。npm、DOM、直接のfetchは使えません。実際のフレームレートはホスト、画面、転送方式に依存します。

AI向け開発手順

手順をコピーし、作りたいウィジェットを説明してください。 API.mdとサンプルファイルも添付 すると、AIに対応APIの範囲を伝えられます。

テキストを入手

検証 & 共有

  • 初期値、長い文、言語、明暗テーマを確認してください。
  • プレビュー、実際の全画面、連続タッチ、ウィジェット切り替えを確認してください。
  • オンライン機能は読み込み中、サービスエラー、インターネット無効を検証します。ZIPに秘密鍵を入れないでください。
  • 同じIDでバージョンを上げて更新し、保存済み設定の維持を確認します。削除すると管理対象の設定も消えます。
  • 共有時は最低Studioバージョン、ライセンス、出典、各プラットフォームでの検証状況を明記してください。
