快速开始

  1. 下载示例 ZIP，并拖入以下列表： 全屏 → 管理小组件。启用后保存顺序和启用状态。
  2. 修改文字和主题，请打开 小组件设置，然后选择 立即在设备上显示。点击设备或虚拟全屏中的卡片，计数就会增加。
  3. 解压 ZIP 并编辑 main.js。新小组件请使用唯一 id；更新时请增加 version。重新压缩的内容应为 文件夹内的文件，不要包含外层文件夹，然后重新导入。
小组件在 PC 的 Studio 中运行，无须在 ESP32 或 Android 上单独安装代码。预览不改变计数；计数仅保存在内存中，Studio 重启后重置。

响应式布局

现有小组件保持 480×320。声明 viewport:1 的新 JavaScript 小组件可使用 api.width、api.height 和 api.contentRect 布局，触控采用相同坐标。

需要支持 viewport:1 的 Windows Studio 0.9.41 / macOS 0.9.40 build148 及更高版本。目前适用于 Mac/Windows 虚拟屏幕，ESP32 和现有 Android 连接保持 480×320 兼容模式。此功能不会提高传输图像的分辨率。

可从这样的简单 render 函数开始。可安装示例还包含触控去重、设置和翻译。

const widget = {
  render(api) {
    api.useThemeBackground?.();
    const c = api.canvas;
    c.fillStyle = '#86E9C6';
    c.font = '24px sans-serif';
    c.textAlign = 'center';
    c.fillText(api.settings.message, 240, 160);
  }
};

APIs & 运行环境

绘图 & 触控

支持传统 480×320 或可选响应式坐标，最多 700 条绘图指令、32KiB 状态。触控使用 packageVersion 3、api.inputs、api.active，并按 sequence 去重。返回及左右导航由 Studio 管理。

设置 & 图片

在 settings.json 中声明文字、开关和选项。支持主题背景、翻译以及符合限制的 JPEG 背景和静态 WebP 精灵图。

网络 & 安全

仅声明必要的 HTTPS 主机并使用 api.httpJson 缓存结果。遵循 Studio 的互联网设置，不提供文件修改、任意命令、摄像头或麦克风 API。

共享宿主服务

系统、媒体、天气的只读快照及声明式新闻、照片服务需要明确的协议和权限，不能当作任意 JavaScript 函数调用。

阅读 API 指南

JavaScript 在同步 render(api) 中运行，不支持 npm、DOM 或直接 fetch。实际帧率取决于宿主、屏幕和传输方式。

测试 & 分享

  • 检查默认值、长文字、语言和明暗主题。
  • 检查预览、实际全屏、连续触控和小组件切换。
  • 在线小组件须测试加载、服务错误和禁用互联网的情况。切勿将密钥放入 ZIP。
  • 使用相同 ID 和更高版本更新，并确认原设置保留。删除小组件会删除其受管理的设置。
  • 分享时请注明最低 Studio 版本、许可证、来源及各平台的测试情况。
