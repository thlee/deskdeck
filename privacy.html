ESP32에 저장된 Wi-Fi 자격정보나 전체 플래시 백업에는 비밀번호가 포함될 수 있습니다. 백업은 사용자가 지정한 위치에 저장하며 지원 문의에 첨부하지 마세요. 선택 기능의 외부 통신 국내 관측 지역은 기상청 XML을 조회합니다. 해외·그 밖의 좌표 지역을 선택하면 MET Norway에 소수점 두 자리로 줄인 위도·경도, 접속 IP 및 앱 식별자가 전송됩니다. 제공처는 IP·좌표를 노르웨이 서버의 접근 기록에 남길 수 있습니다. 캐시로 반복 전송을 줄입니다. 도시 이름 검색은 동봉 GeoNames 목록에서 처리하므로 검색어를 외부 검색 서비스로 보내지 않습니다. 운영체제 위치 사용은 OS 권한에 따르며 수동으로 지역을 선택할 수 있습니다. 사이트 아이콘을 가져오면 해당 사이트에 요청을 보냅니다. Runtime이 없는 PC에서는 설치 중 Microsoft 서버에서 내려받습니다. Microsoft 개인정보처리방침 https://aka.ms/privacy 와 WebView2 안내 https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/data-privacy 를 참고해 주세요. Android 앱 배포와 USB 드라이버 QR/브라우저 설치는 PC가 일시적으로 제공하는 로컬 HTTP 다운로드 페이지를 사용합니다. 페이지를 열 수 있는 같은 네트워크의 상대에게 APK가 노출될 수 있으므로 신뢰하는 네트워크에서 사용하고 완료 후 설치 창을 닫아 주세요. 앱 설치 여부는 Android가 확인하며 공개 배포 APK는 디버깅을 끈 release 빌드이며, 기존 앱 업데이트를 위해 이전 서명 인증서의 동일성을 유지합니다. 앱 스토어 배포판은 아닙니다.
