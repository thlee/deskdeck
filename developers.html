예제 ZIP 받기AI와 함께 만들기

권장: Windows Studio 0.9.42+ · macOS 0.9.40 build148+
별도 선택 설치 · 인터넷 불필요 · 예제 MIT 라이선스

빠른 시작화면에 맞는 배치파일과 코드API와 실행 환경AI 개발 지침검증과 배포

빠른 시작

  1. 예제 ZIP을 다운로드해 Studio의 전체화면 → 위젯 관리 목록에 그대로 놓으세요. 사용을 켜고 순서·사용 여부를 저장합니다.
  2. 위젯 설정에서 문구·테마 배경을 바꾸고, 기기에서 지금 보기를 누르세요. 기기나 가상 전체화면의 카드를 누르면 숫자가 올라갑니다.
  3. 수정할 때는 ZIP을 풀고 main.js를 편집하세요. 새 위젯은 고유 id를 쓰고, 기존 위젯의 수정본은 version을 높입니다. 폴더 자체가 아닌 폴더 안의 파일들을 ZIP으로 묶어 다시 가져옵니다.
위젯은 PC의 Studio에서 실행됩니다. ESP32·Android에 코드를 따로 설치하지 않습니다. 미리보기는 카운트를 바꾸지 않으며, 카운트는 앱 재시작 시 초기화되는 메모리 상태입니다.

화면에 맞는 배치

기존 위젯은 480×320 그대로 동작합니다. viewport:1을 선언한 새 JavaScript 위젯은 api.width·api.height·api.contentRect로 가로·세로 화면에 맞춰 배치하고 같은 좌표로 터치를 받습니다.

viewport:1을 지원하는 Windows Studio 0.9.41 / macOS 0.9.40 build148 이상이 필요합니다. 현재 맥·윈도우 가상 화면에 적용되며, ESP32·현재 안드로이드 연결은 480×320 호환 모드입니다. 전송 이미지 해상도가 높아지는 기능은 아닙니다.

반응형 예제 ZIP 받기

파일과 코드

manifest.json    # ID, version, permissions
main.js          # render(api)
settings.json    # message, theme
locales/         # ko, en, ja, zh-Hans
LICENSE.txt

이렇게 작은 render 함수부터 시작할 수 있습니다. 설치 가능한 전체 예제에는 터치 중복 방지와 설정·번역도 들어 있습니다.

const widget = {
  render(api) {
    api.useThemeBackground?.();
    const c = api.canvas;
    c.fillStyle = '#86E9C6';
    c.font = '24px sans-serif';
    c.textAlign = 'center';
    c.fillText(api.settings.message, 240, 160);
  }
};

개발 자료 묶음 받기 — 예제 소스 · API · AI 지침

자료 묶음은 압축을 풀어 읽는 개발 자료입니다. Studio에 설치할 파일은 위의 예제 ZIP입니다.

API와 실행 환경

그리기와 터치

기본 480×320 · 선택형 반응형 좌표, 700개 이하 그리기 명령, 32KiB 상태. 터치는 packageVersion 3에서 api.inputs로 받고 api.active와 sequence를 확인합니다. 상단 뒤로·좌우 이동은 Studio가 관리합니다.

설정과 이미지

settings.json으로 문구·체크박스·선택 목록을 만듭니다. 테마 배경, 번역, 제한된 JPEG 배경·WebP 스프라이트를 사용할 수 있습니다.

인터넷과 보안

필요한 HTTPS 호스트만 선언하고 api.httpJson의 캐시를 사용합니다. Studio 인터넷 설정을 따릅니다. 파일 수정·임의 명령 실행·카메라·마이크 API는 제공하지 않습니다.

공용 기능 재사용

시스템·미디어·날씨의 읽기 전용 스냅샷, 선언형 뉴스·사진 서비스는 별도 계약과 권한이 필요합니다. JavaScript에서 임의의 함수 이름으로 호출할 수 있는 기능은 아닙니다.

API 안내서 읽기

JavaScript는 동기식 render(api)에서 실행됩니다. npm·DOM·직접 fetch는 지원하지 않습니다. 실제 화면은 장치와 전송 속도에 맞춰 표시되므로 프레임 속도를 보장하지 않습니다.

AI 개발 지침

아래 지침을 복사한 뒤 원하는 기능을 적으세요. 개발 자료의 API.md와 예제 파일도 함께 첨부하면 지원 범위를 더 정확히 전달할 수 있습니다.

검증과 배포

  • 기본 설정·긴 문구·언어·밝고 어두운 테마를 확인하세요.
  • 미리보기와 실제 전체화면, 연속 터치·중복 입력·위젯 전환을 확인하세요.
  • 인터넷 위젯은 로딩·응답 오류·인터넷 사용 끄기를 확인하세요. 비밀키를 ZIP에 넣지 마세요.
  • 동일 id의 새 버전으로 업데이트하고 기존 설정이 유지되는지 확인하세요. 삭제 후 재설치는 설정을 지울 수 있습니다.
  • 공유할 때 최소 Studio 버전·라이선스·출처·플랫폼별 검증 여부를 적으세요.
예제의 MIT 라이선스는 해당 예제에만 적용됩니다. Studio 전체나 다른 위젯·이미지의 사용권을 뜻하지 않습니다. 위젯 등록은 자동으로 공홈에 게시되는 절차가 아닙니다.

JavaScript ZIP 검증은 Studio에서 진행하세요. 기존 SDK의 브라우저 미리보기는 선언형 JSON용입니다.
