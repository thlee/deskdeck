Privacy & communication

What Baroham stores and which services it communicates with.

On a first visit, the website follows your browser language. A language you select is saved in this browser’s local storage and takes priority on later visits. The preference is not sent to a server. Clearing the site’s browser data resets it.

Baroham public free evaluation privacy and communication notice Version: 2026-10-18 · Provider: 이태호 · Contact: deskdeck.app@gmail.com Local storage Installed Studio keeps settings under %LOCALAPPDATA%\DeskDeck; program files are under %LOCALAPPDATA%\Programs\DeskDeck. An explicitly selected data directory overrides the settings location. Local data includes buttons, executable paths, shortcuts/macros, paired devices, window size, selected city, weather cache and diagnostic logs. Macro text is encrypted with Windows user-scoped DPAPI and decrypted for editing/execution. This is not a password-manager guarantee against malware running as the same user. Optional macro recording Keyboard input and shortcuts are collected locally only while the user starts a recording. Enabling the separate text-capture option can also record editable text exposed by accessibility APIs. Password fields are excluded; captured strings are encrypted like other macro text. They are not sent to the provider. Review the captured steps before saving. Device communication Studio exchanges its rendered deck/widget images, action identifiers and touch input with registered devices. It does not broadcast the entire PC desktop. Wi-Fi uses local discovery and pairing; the phone wireless connection uses TLS. AOA uses USB. A registered device can trigger configured PC actions; do not share pairing credentials. ESP32 Wi-Fi settings and full flash backups can contain passwords. Backups stay in the user-selected location and must not be sent as support attachments. Optional external services Korean observation locations use the KMA XML feed. Other coordinate locations use MET Norway: the selected latitude/longitude rounded to two decimals, your IP address and app identification are sent to the provider. MET Norway may log IP addresses and coordinates in Norway. Responses are cached. City-name searches use the bundled GeoNames catalog and are not sent to a search service. OS location follows OS permissions; manual city selection is available. Fetching a website icon contacts that website. Installing and using an additional widget contacts its provider. Coin prices queries Upbit public APIs. News retrieves the default NASA feed or public RSS/Atom URLs configured by the user. Providers receive the connection IP address and ordinary HTTP request information. Feed URLs and widget options are stored locally; normalized news titles and links are cached in memory. Tapping a headline opens its original website in the PC browser. Check the source and usage terms before installing a widget ZIP or adding a feed. Microsoft WebView2 WebView2 uses Microsoft Defender SmartScreen by default. SmartScreen information and diagnostic data may be sent to Microsoft; the Evergreen Runtime can receive Microsoft updates. If absent, setup downloads the Runtime from Microsoft. Read https://aka.ms/privacy and https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/data-privacy . Android distribution and optional USB driver QR/browser APK installation uses a temporary local HTTP download page. Other parties able to reach the page on the network may download the APK. Use a trusted network and close the install window afterwards. Android controls app installation; the public release APK disables debugging and retains the previous signing certificate identity for in-place updates. It is not an app-store release. UsbDk for AOA is a separate optional installation, not bundled or silently installed. ADB/debugging tools are excluded. Permissions and support Normal setup and basic use do not require administrator rights. Firewall changes and the optional driver can require separate elevation. Sign-in startup can be changed in General settings. Exit from the tray to stop Studio communication/input processing. Baroham does not automatically upload account, usage or crash information to its provider. Only email/material you choose to send reaches the provider. Logs can contain paths and error messages; review them before sharing. Public website and downloads The site and downloads are hosted by GitHub Pages and GitHub Releases. GitHub may process IP addresses and service-operation data under its own privacy statement: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement . The introduction site includes no separate advertising, visitor analytics or donation payments. Public GitHub issues are visible to everyone; do not post personal data or passwords. Removal Exit Studio and uninstall using Windows Apps. To remove settings, carefully delete %LOCALAPPDATA%\DeskDeck and any backup/data folders you selected, after preserving needed information. Android data can be cleared in Android App info. Use the ESP32 device setup/reset guidance for board credentials. Deleted settings may not be recoverable. Privacy/security contact: deskdeck.app@gmail.com. Optional idle screen advertisements Disabled by default. When enabled and a supported ESP32 or Android device is connected, Baroham downloads an ad catalog and static images from its official website. No user identifiers, usage history, impression reports or click reports are sent. GitHub, the hosting provider, may process connection information such as the requesting IP address. Ad images are held temporarily in PC and device memory; links never open automatically. You can turn this feature off at any time. The bundled Baroham introduction is shown when no downloaded ad is available or valid. Manual media library Manually registered links, local file paths, names, favorites and recent Baroham open-request times are stored in the PC profile and included in profile exports. Browser playback is not automatically collected; tabs and pages are not inspected for media registration. OS now-playing metadata is still used for current-track display and media controls. Legacy automatic records remain in the profile but are hidden unless explicitly pinned. Existing buttons remain intact. The media library is not sent to the provider. When you explicitly add a URL with a blank name, Studio requests that URL from the service to retrieve its media title. It does not use browser login cookies or account credentials and does not execute page scripts. The service may process ordinary request information such as your IP address. If no title is available, Studio uses a name derived from the provider and address. Themes, media artwork and video User-selected theme images and videos may be stored in the PC profile/cache and transferred to supported Android devices for reuse in app-internal storage. They are not uploaded to the provider. Clearing a video selection removes the setting reference; it does not delete the original video or existing cached files. Retrieving media artwork requests the media service or image host. That service may process normal request information such as your IP address, and retrieved images are cached on the PC. Additional widgets may contact their own external services; consult the widget's notice.
