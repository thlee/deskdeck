开始前

您需要了解的事项。

需要购买设备吗？

不需要。可先使用虚拟 Baroham 窗口，以鼠标或触摸显示器操作，并调整大小适配副屏。

免费吗？以后会收费吗？

此公开版免费，无时间限制，也不会自动扣费。您获得版本的免费使用权不会被追溯改为收费许可。

Android 如何连接？

需要 Android 5.0+。同一局域网的 Wi-Fi 最容易入门。也支持 USB，但 PC 可能需要可选 UsbDk 驱动。兼容性因设备而异，正常连接不需要 USB 调试。

安装包为什么这么大？

包含 Windows 运行库、Android 应用、ESP32 固件工具，以及履行第三方许可证所需的对应源码和重建资料。正常使用无需单独安装 Python。

能在工作中使用或输入密码吗？

条款允许工作场所使用，但须遵守组织安全政策。加密宏文字在执行时解密并输入当前目标窗口。Baroham 不能替代密码管理器。

Mac 和 iPhone 呢？

公开安装包面向 Windows x64。macOS 版正在开发，本网站不提供下载。目前没有 iPhone 应用。

在哪里寻求帮助？

可提交 GitHub issue 或发邮件至 deskdeck.app@gmail.com，附上版本、连接方式、复现步骤和错误信息。勿公开密码、完整设备备份或个人配置文件。
