  • 무료, 기간 제한 없이현재 버전은 개인·업무 환경에서 무료로 이용할 수 있습니다. 가입이나 결제 없이 사용할 수 있습니다.
  • 설정은 내 PC에버튼과 매크로는 로컬에 저장합니다. 제공자에게 사용량이나 오류 기록을 자동 전송하지 않습니다. 날씨 등 선택 기능과 런타임에는 외부 통신이 있습니다.

  • 소스 공개와 무료 사용은 별개Studio·Android 자체 소스는 비공개입니다. 오픈소스 고지와 필요한 대응 소스·펌웨어 재링크 자료는 설치파일에 함께 제공합니다.

Before you begin

궁금하실 만한 것들.

별도 기기를 구입해야 하나요?

아닙니다. 가상 DeskDeck 창만으로 시작할 수 있습니다. 마우스로 클릭하거나, 터치 모니터에 창을 놓고 직접 누르세요. 창 크기를 바꿔 보조 모니터를 활용할 수도 있습니다.

정말 무료인가요? 나중에 결제가 되나요?

현재 공개 버전은 무료이며 기간 제한이나 자동 결제가 없습니다. 이미 받은 이 버전의 무료 사용권을 소급 유료화하지 않습니다.

Android는 어떤 방식으로 연결하나요?

Android 8.0 이상이 필요합니다. 같은 로컬 네트워크의 Wi-Fi로 시작하는 방법이 가장 간단합니다. USB AOA도 지원하지만 PC에 선택적 UsbDk 드라이버 설치가 필요할 수 있으며 기기별 호환성이 다를 수 있습니다. USB 디버깅은 일반 연결에 필요하지 않습니다.

설치파일 용량이 왜 큰가요?

Windows 런타임, Android 앱, ESP32 펌웨어 설치 도구에 더해 라이선스 조건을 지키기 위한 대응 소스와 재빌드 자료를 함께 제공합니다. 일반 사용에 별도 Python 설치는 필요하지 않습니다.

회사 PC나 비밀번호 입력에 사용해도 되나요?

업무 환경 사용은 약관상 허용하지만 회사 보안 정책을 먼저 따라 주세요. 문자열 매크로는 암호화 저장되더라도 실행 시 대상 창에 실제로 입력됩니다. 비밀번호 관리자를 대신하는 보안 기능은 아닙니다.

Mac과 iPhone도 사용할 수 있나요?

이번 공개 설치파일은 Windows x64용입니다. macOS는 개발 중이며 이 페이지에서 배포하지 않습니다. iPhone 앱은 현재 제공하지 않습니다.

질문이나 오류는 어디로 보내나요?

GitHub 이슈 또는 deskdeck.app@gmail.com으로 앱 버전, 연결 방법, 재현 순서, 오류 문구를 알려 주세요. 공개 이슈에 비밀번호, 기기 전체 백업, 개인 설정 파일을 올리지 마세요.
