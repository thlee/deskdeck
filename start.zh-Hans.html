01. 在 Windows 上安装 Studio

  1. 下载： 官方 Windows 安装程序。需要 Windows 10 1809 或更高版本，或 Windows 11，x64 架构。
  2. 运行并查看条款及隐私声明。默认安装目录为 %LOCALAPPDATA%\Programs\DeskDeck.
  3. 如未安装 Microsoft WebView2，安装程序会下载它，此时需要联网。
  4. 打开 Baroham Studio。无需其他设备，可先使用虚拟窗口。

本软件为开发中的免费软件，使用前请查看条款。 使用条款 · 保证与责任

Windows 可能显示“未知发布者”警告。 此版本没有 Authenticode 签名。请核对官方仓库、文件名和发布的 SHA-256。不要关闭安全软件或组织限制；安装被阻止时请联系管理员。

常规安装不需要管理员权限。可在 Studio 常规设置中修改自动启动行为。

02. 使用虚拟 Baroham

  1. 在 Studio 常规设置中启用未连接设备时显示虚拟 Baroham。
  2. 在独立的 Baroham 窗口中点击按钮，或在触摸显示器上轻触。
  3. 移至目标显示器，拖动边缘调整大小。位置和大小会保存。
  4. 也可选择匹配最近连接设备的尺寸。

小型触摸显示器或闲置屏幕即可用作控制面板，无需新硬件或手机应用。

03. 连接 Android 手机

让旧 Android 手机或平板焕发新用途 →

支持 Android 5.0 及以上。先将手机和 PC 连接到同一个可信局域网。只要网络允许互通，有线 PC 和 Wi-Fi 手机也可配合使用。

准备应用

  1. 在 Studio“设备”菜单中打开 Android 手机连接指南，选择应用是否已安装。
  2. 如有需要，用手机扫描 Studio 的二维码，在浏览器中下载 APK。
  3. Android 提示时，允许该浏览器安装未知来源应用并确认安装，之后可关闭权限。请勿绕过组织的安装政策。
  4. 在手机上打开 Baroham，并继续 Studio 中的安装完成步骤。

通过 Wi-Fi 连接

  1. 在 Studio 和手机应用中均选择 Wi-Fi。
  2. 找到 PC，输入 Studio 显示的初始六位代码。
  3. 出现按钮屏幕表示连接成功。以后会使用保存的配对信息重新连接。

通过 USB 连接

  1. 解锁手机，用 USB 数据线连接 PC。
  2. 在手机应用选择 USB 标签，在 Studio 选择 USB 线缆选项。
  3. 必要时按指南单独安装可选的 UsbDk 驱动。此系统驱动需要管理员批准，既不捆绑也不自动安装。
  4. 在手机上批准 USB 配件请求。USB AOA 不需要 Wi-Fi 配对用的六位代码。

正常 Wi-Fi 和 AOA 连接不需要 USB 调试。AOA 兼容性取决于手机、线缆和 PC 的 USB 环境。已注册设备会逐台自动重连。更新后若停留在“正在连接 PC”，请重新插拔 USB 线；某些旧平板需要此步骤。

应用更新与屏幕设置

点击按钮屏幕底部中央的小齿轮。可设置亮度、空闲时间、帮助、版本及更新。更新会检查所连接 Studio 的应用包，并打开浏览器安装指南。全屏小组件中需先返回按钮屏幕才能打开设置。

04. 连接 ESP32 开发板

目前支持的开发板是 JC3248W535。该固件不适用于所有 ESP32 屏幕。

  1. 使用 USB 数据线将开发板连接到 PC。
  2. 在 Studio“设备”菜单打开 ESP32 连接指南，并选择 JC3248W535。
  3. 新开发板可先选择是否备份原固件，再安装 Baroham 固件。核对开发板与端口，刷写期间保持线缆连接。
  4. 确认 USB 下按钮屏幕和输入正常。
  5. 无线使用时，请在 USB 连接状态下完成 Wi-Fi 配置。之后可在同一网络中不通过 USB 传输数据，但仍需要供电。

完整闪存备份可能包含 Wi-Fi 密码，勿附在公开 issue 或支持邮件中。捆绑固件：0.8.2。

05. 创建按钮与宏

  1. 在 Studio 预览中选择按钮。
  2. 设置名称与操作。可选已安装应用、输入应用路径或快捷键，或选择系统信息。
  3. 选择内置或自定义图标。
  4. 保存并应用到设备，也会更新已连接手机或虚拟窗口。

排列按钮与添加图片

右击预览可复制、剪切、粘贴、向左或右插入、删除或重置按钮。插入和删除会跨页移动后续按钮，M 保持在末尾。重置仅清空内容，保留位置。

在操作列表选“空白按钮”，通过图标库导入图片。图片保持比例，点击无操作。“+”空位可打开 Studio 编辑器。修改图片后请保存并应用。

按钮组合宏

按顺序组合按钮操作、快捷键、文字和延迟。选择输入类型、填写值并添加到选中步骤下方。延迟以秒为单位，支持小数。Tab 和 Enter 属于快捷键输入；文字也可选输入后发送 Enter。

宏编辑器的确认按钮将修改返回按钮编辑器。需在 Studio 保存并应用才会持久保存。可在底部状态区或托盘菜单停止正在运行的宏。

宏文字使用 Windows 账户加密保存，但运行时会作为实际输入发送。请先在安全窗口测试。密码复选框仅隐藏列表中的文字，并不使本应用成为密码管理器。

管理页面

可添加、重置和排列页面。大屏幕会按保存顺序重新排列普通按钮，可能减少页数。M 媒体页保持最后。使用屏幕边缘或滑动循环翻页。

06. 全屏小组件

可选择时钟、猫咪、媒体等内置小组件。在管理界面启用并拖动排序，手动打开或空闲后显示。

轻触左右边缘或滑动可切换。点击时钟或猫咪画面可返回按钮，交互小组件提供返回控件。小组件保持比例，周围空间匹配背景，并通过小幅定时位移减少固定显示。

Android 空闲亮度在手机应用内设置。关闭 Windows 显示器不等于让整台 PC 睡眠。PC 完全睡眠时无法继续正常通信。

07. 排查连接问题

无法发现 PC 或打开二维码页面。

检查两端是否在同一局域网、访客 Wi-Fi 是否阻止互通。按 Studio 排查指南仅允许必要的防火墙访问。下载期间请保持安装指南打开。

USB 可以充电，但无法连接。

使用数据线而非仅充电线。Android 请检查应用 USB 模式、配件授权和 AOA 驱动；ESP32 请检查 Studio 中的端口与支持型号。

关闭窗口是否会退出 Studio？

Studio 可能继续在托盘运行。完全退出请使用托盘的“退出”；点击托盘图标可重新打开设置。

Android 无法安装应用。

请通过 Studio 二维码指南在浏览器重新下载 APK。不同证书签名的应用无法覆盖更新。卸载旧应用前确认所需配对和设置；政策限制请联系管理员。

外部小组件突然停止了。

在 Studio 0.9.41 中，如果检测到外部小组件发生执行错误或违反安全规则，该小组件可能会被自动停用。请在 Studio 中打开全屏小组件 → 管理小组件，查看停用原因，解决问题后手动重新启用。普通的网络断开或服务器错误不会导致小组件被自动停用。

报告问题

请使用 GitHub issue 或发送邮件至 deskdeck.app@gmail.com。请附版本、连接方式、复现步骤和错误信息，勿发送密码、个人设置或完整设备备份。

08. 退出与卸载

从托盘退出 Studio，再在 Windows 已安装应用中卸载 Baroham。设置可能保留在 %LOCALAPPDATA%\DeskDeck。删除该文件夹或自选备份文件夹前，请保存需要的数据。

UsbDk 是独立程序，不再需要时可单独卸载。删除 Android 应用数据或 ESP32 配对信息请按设备指南操作。

使用 Android 触控板

在 Studio“设备 → 触控板”启用后，点击手机按钮屏幕底部的触控板图标。USB 和 Wi-Fi 均支持移动、左右点击、拖动和滚动。游戏保护或提权应用窗口可能限制输入。
