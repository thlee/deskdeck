目标：Windows Studio 0.9.41+ / macOS 0.9.40 build148+。

1. 默认制作外部 JavaScript ZIP，需要触控时使用 packageVersion 3。
2. 将 manifest.json、main.js、settings.json 放在 ZIP 根目录，指定唯一 ID 和 major.minor.patch 版本。
3. 不要假设或编造文档未列出的 API、npm、DOM、fetch、文件访问、OS 执行、摄像头或麦克风功能。先说明不支持的要求。
4. 默认采用原有 480×320 坐标。响应式仅用于支持 viewport:1 的 Windows 0.9.41 / macOS 0.9.40 build148 及更高版本，在 requires 声明 canvas/settings/touch/viewport，并每帧使用 api.width、height、contentRect 布局。触控已在同一坐标系内，可能为小数。现有设备连接会回退至 480×320，顶部和左右导航由 Studio 管理。
5. render(api) 必须同步，绘图操作不超过 700，状态不超过 32KiB。
6. api.active 为 false 的预览不要改变游戏状态，避免重复处理 sequence。
7. 用 api.useThemeBackground?.() 请求主题，支持设置、韩语/英语/日语/中文及长文字。
8. 仅在需要互联网时声明准确 HTTPS 主机，使用 api.httpJson 缓存。处理加载、失败及禁网情况，不嵌入密钥。
9. state 不是永久存储。用户选项放在 settings.json。更新同 ID 时增加版本，保持设置兼容。
10. 提供文件树、所有文件内容、根结构正确的 ZIP、使用方法、许可证和来源、最低版本及验证清单。
11. 未在实际 Studio 运行就不要声称测试完成，明确区分 Windows、Mac 和设备的未验证项。

Windows 0.9.41 / macOS 0.9.40 build148 及更高版本只允许普通 JSON 状态（序列化 UTF-8 ≤32KiB，深度≤20，值节点≤4096）。不要保存缓冲区、类型化数组、Map/Set、Date、循环引用或非有限数值。已声明的 HTTPS 主机必须仅解析为公网 IP；内部地址被阻止，并在接收过程中限制响应大小。上述支持版本提供这些强化检查。

Windows 0.9.41 / macOS 0.9.40 build148 及更高版本会在发生执行错误或安全规则违规时立即停用微件。宿主保存原因和时间、取消待处理任务，并阻止包括预览在内的再次执行。Studio 重启、ZIP 更新或重新安装均不会自动解除停用。只有用户在微件管理中查看原因并明确重新启用后才能执行。重新安装已停用 ID 的 ZIP 只替换文件，不执行安装预览，也不会解除停用。再次违规时会重新停用。离线、DNS 查询失败、普通网络超时、服务器错误及无效 JSON 响应不会导致停用；内网 IP、未声明 URL 及响应超限会导致停用。如果无法保存停用记录，会提示错误，并在本次运行中维持内存中的阻止状态。
