添付のBarohamウィジェットAPIガイド（API.ja.md）とHello例を基に作成してください。
作りたい機能：[ここに記入]
対象：Windows Studio 0.9.41+ / macOS 0.9.40 build148+。

1. 原則として外部JavaScript ZIPにし、タッチが必要ならpackageVersion 3を使います。
2. manifest.json、main.js、settings.jsonをZIPルートに置き、固有IDとmajor.minor.patchを指定します。
3. 未記載API、npm、DOM、fetch、ファイルアクセス、OS実行、カメラ・マイクを想定しません。未対応要件は先に説明してください。
4. 既定は480×320です。レスポンシブはWindows 0.9.41 / macOS 0.9.40 build148以降で、requiresにcanvas/settings/touch/viewportを宣言し、毎フレームapi.width・height・contentRectで配置します。タッチは同一座標で小数の場合もあります。既存機器接続は480×320に戻ります。上部・左右ナビゲーションはStudio管理です。
5. render(api)は同期処理、描画700操作以内、状態32KiB以内にします。
6. api.activeがfalseのプレビューでゲームを進めず、sequenceを重複処理しません。
7. テーマはapi.useThemeBackground?.()で要求し、設定・韓国語/英語/日本語/中国語・長文に対応します。
8. 通信が必要な場合のみ正確なHTTPSホストを宣言し、api.httpJsonのキャッシュを使います。読み込み、失敗、通信無効を考慮し秘密鍵は入れません。
9. stateは永続保存ではありません。利用者設定はsettings.jsonに置きます。同じIDの更新は版を上げ、設定互換性を維持します。
10. ファイル構造、全内容、正しいルートのZIP、使い方、ライセンス・出典、最低版、検証リストを提供してください。
11. 実際のStudioで試していなければ検証済みと書かず、Windows・Mac・機器別の未検証事項を明記してください。

Windows 0.9.41 / macOS 0.9.40 build148以降の状態は通常のJSONのみです（シリアライズしたUTF-8で32KiB以下、深さ20・値ノード4096以下）。バッファ・型付き配列・Map/Set・Date・循環参照・非有限数を保存しないでください。宣言済みHTTPSホストは公開IPのみに解決する必要があり、内部アドレスを拒否して受信中に応答サイズを制限します。上記の対応バージョンで強化検査を利用できます。

Windows 0.9.41 / macOS 0.9.40 build148以降では、実行エラーや安全規則違反が発生したウィジェットを即座に停止します。理由と日時を保存し、待機中の処理を取り消してプレビューを含む再実行を防ぎます。Studio再起動・ZIP更新・再インストールでも自動解除しません。ウィジェット管理で理由を確認し、利用者が明示的に再度有効にする必要があります。停止中のIDを再インストールするとファイルだけを置き換え、インストール時のプレビュー実行や停止解除は行いません。再違反時は再び停止します。オフライン・DNS解決失敗・通常の通信タイムアウト・サーバーエラー・不正なJSON応答では停止しません。内部IP・未宣言URL・応答サイズ上限違反は停止対象です。停止記録の保存に失敗した場合は通知し、現在の起動中はメモリ内のブロックを維持します。
