Getting started

From setup to your first button.

Install Studio, choose a screen,
then try one simple action.

01. Install Studio on Windows

  1. Download the official Windows installer. You need Windows 10 1809 or later, or Windows 11, on x64.
  2. Run it and review the terms and privacy notice. The default install folder is %LOCALAPPDATA%\Programs\DeskDeck.
  3. If Microsoft WebView2 is missing, setup downloads it. An internet connection is required in that case.
  4. Open DeskDeck Studio. You can start with the virtual window, without another device.

Check macro settings and targets before running. Terms · Warranties and liability

Windows may show an unknown publisher warning. This release does not have an Authenticode signature. Check the official repository, filename and release SHA-256. Do not disable security software or organization restrictions; contact your administrator if installation is blocked.

Normal installation does not require administrator rights. You can change startup behavior in Studio’s general settings.

02. Use virtual DeskDeck

  1. In Studio’s general settings, enable virtual DeskDeck when no device is connected.
  2. Click buttons in the separate DeskDeck window, or tap them on a touch monitor.
  3. Move it to your chosen monitor and drag its edges to resize it. Size and position are saved.
  4. You can also choose to match the size of the most recently connected device.

A small touch monitor or spare display can become a control panel. No new hardware or phone app is required.

03. Connect an Android phone

Android 5.0 or later is supported. First connect the phone and PC to the same trusted local network. A wired PC and a Wi-Fi phone can work together if the network allows them to communicate.

Prepare the app

  1. Open the Android phone connection guide in Studio’s Devices menu. Select whether the app is already installed.
  2. If needed, scan Studio’s QR code with your phone and download the APK in your browser.
  3. When Android asks, allow that browser to install unknown apps and approve installation. You can turn that permission off afterward. Do not bypass your organization’s installation policies.
  4. Open DeskDeck on the phone and continue with the installation-complete step in Studio.

Connect over Wi-Fi

  1. Select Wi-Fi in both Studio and the phone app.
  2. Find your PC and enter the initial six-digit code shown in Studio.
  3. The button screen confirms connection. Saved pairing details are used to reconnect later.

Connect with USB

  1. Unlock the phone and connect it to the PC with a USB data cable.
  2. Select the USB tab in the phone app and the USB cable option in Studio.
  3. If needed, follow the guide to install the optional UsbDk driver separately. This system driver requires administrator approval and is neither bundled nor installed automatically.
  4. Approve the USB accessory request on the phone. USB AOA does not require the six-digit Wi-Fi pairing code.

Normal Wi-Fi and AOA connections do not require USB debugging. AOA compatibility depends on the phone, cable and PC USB environment. Registered devices reconnect automatically, one at a time. If the app remains on Connecting to PC after an update, unplug and reconnect the USB cable; some older tablets require this step.

App updates and display settings

Tap the small gear at the bottom center of the button screen. Settings include brightness, idle time, help, app version and updates. Updating checks the connected Studio’s app package and opens browser installation guidance. Return from a full-screen widget to the button screen to open settings.

04. Connect an ESP32 board

The currently supported board is JC3248W535. Its firmware is not suitable for every ESP32 display.

  1. Connect the board to your PC using a USB data cable.
  2. Open the ESP32 board connection guide in Studio’s Devices menu and select JC3248W535.
  3. For a new board, choose whether to back up its existing firmware before installing DeskDeck firmware. Confirm the board and port, and keep the cable connected during flashing.
  4. Check that the button screen and input work over USB.
  5. For wireless use, complete Wi-Fi setup while still connected over USB. The board then works on the same network without USB data, but still needs power.

Full flash backups can contain Wi-Fi passwords. Do not attach them to public issues or support emails. Bundled firmware: 0.8.1.

05. Create buttons and macros

  1. Select a button in the Studio preview.
  2. Choose its name and action. Pick an installed app, enter an app path or shortcut, or choose system information.
  3. Choose a built-in or custom icon.
  4. Save and apply to the device. This also applies settings to a connected phone or virtual window.

Arrange buttons and add images

Right-click the preview to copy, cut, paste, insert on the left or right, delete or reset a button. Insertion and deletion shift following buttons across pages while M stays last. Reset clears the contents but keeps the position.

Choose Blank button in the action list and use the icon library to import your own image. The image keeps its proportions and tapping it does nothing. A + add slot opens the Studio editor. Save and apply after changing an image.

Button combination macros

Combine button actions, shortcuts, text and delays in order. Select an input type, enter its value and add it below the selected step. Delays use seconds and accept decimals. Tab and Enter are shortcut inputs; text also has an option to send Enter afterward.

The macro editor’s confirmation button returns your changes to the button editor. Save and apply in Studio to persist them. Stop a running macro from the bottom status area or tray menu.

Macro text is encrypted at rest using your Windows account, but is sent as actual input when run. Test in a safe window first. The password checkbox hides text in the list; it does not turn the app into a password manager.

Manage pages

Add, reset and arrange pages. Larger displays reflow normal buttons in saved order and can reduce the number of pages. The M media page stays last. Use screen edges or swipes to cycle through pages.

06. Full-screen widgets

Choose clocks, Neko, media and other built-in widgets. Enable them and drag to reorder them in widget management. Open a widget manually or after an idle interval.

Tap the left or right edge, or swipe, to change widgets. Tap a clock or Neko screen to return to buttons; interactive widgets provide a return control. Widgets keep their aspect ratio, surrounding space matches the background, and small periodic shifts reduce fixed positioning.

Android idle brightness is configured in the phone app. Turning off the Windows monitor differs from putting the entire PC to sleep. Normal communication cannot continue while the PC is fully asleep.

07. Troubleshoot a connection

PC discovery or the QR page does not work.

Check that both devices are on the same local network and that guest Wi-Fi is not blocking communication. Use Studio’s troubleshooting guidance to allow only the required firewall access. Keep the installation guide open while downloading.

USB charges the device but does not connect.

Use a data cable rather than a charge-only cable. For Android, check USB mode in the app, accessory approval and the AOA driver. For ESP32, check the port and supported board model in Studio.

Does closing the window quit Studio?

Studio can keep running in the tray. Use Quit in the tray menu to exit completely, or click the tray icon to reopen settings.

Android refuses to install the app.

Try downloading the APK again through Studio’s QR guide in your browser. An app signed with a different certificate cannot be updated in place. Check any pairing or settings you need before uninstalling an old app. Contact your administrator about policy restrictions.

Report a problem

Use GitHub issues or email deskdeck.app@gmail.com. Include the version, connection method, steps and error message. Do not send passwords, personal settings or full device backups.

08. Quit and uninstall

Quit Studio from the tray, then remove DeskDeck in Windows Installed apps. Settings may remain in %LOCALAPPDATA%\DeskDeck. Back up what you need before removing that folder or your own backup folders.

UsbDk, if installed, is a separate program and can be uninstalled separately when no longer needed. Follow the device instructions to remove Android app data or ESP32 pairing details.
