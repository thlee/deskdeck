스마트폰 PC 리모컨부터 업무용 매크로 패드까지

바로함은 PC의 앱 실행·단축키·파일 열기 등을 화면의 버튼으로 사용하는 프로그램입니다. 안 쓰는 스마트폰이나 오래된 안드로이드 태블릿을 책상 위 컨트롤 패널로 활용할 수 있습니다.

앱과 단축키를 손이 닿는 곳에

메일, 브라우저, 작업 폴더와 복사·붙여넣기 같은 동작을 버튼에 지정할 수 있어요. 구형 태블릿의 넓은 화면에는 버튼을 더 크게 배치해 두면 좋아요.

반복 작업은 버튼 조합 매크로로

검색 홈페이지를 열고 자주 찾는 단어를 입력하는 과정을 버튼 하나에 담을 수 있어요. 단축키·문자열·대기 시간을 순서대로 조합하면 됩니다.

출근하면 작업 환경부터

작업 환경 복원을 길게 누르기에 지정해 두면 좋아요. 기기 화면을 0.5초 꾹 눌러 저장한 앱과 창 배치를 불러올 수 있어요.

쉬는 동안에는 시계와 위젯

일정 시간 사용하지 않으면 시계나 고양이 위젯을 표시하도록 설정할 수 있어요. 뉴스·어항·모닥불 같은 추가 위젯으로 책상을 꾸며도 좋아요.

오래된 안드로이드폰, 무엇을 준비하면 되나요?

  • Windows PC: Windows 10 1809 이상 또는 Windows 11, x64 환경에서 Studio를 실행합니다.
  • 휴대폰 또는 태블릿: Android 5.0 이상을 지원하며 두 기기에 같은 Android 앱을 사용합니다.
  • 연결: 같은 로컬 네트워크의 Wi-Fi 또는 USB 데이터 케이블을 사용합니다. PC는 유선 LAN에 연결되어 있어도 됩니다.

예를 들어 Galaxy S8(Android 9)은 작은 단축키 패널로, LG G Pad 8.0(Android 5.0.2)은 넓은 버튼·위젯 화면으로 활용할 수 있습니다. USB 호환성은 기기와 케이블에 따라 다를 수 있습니다.

안 쓰는 스마트폰으로 PC 단축키 만들기

  1. PC에 바로함 Studio 설치

    Windows 설치파일을 내려받고 Studio를 실행하세요.

  2. 휴대폰에 바로함 앱 설치

    Studio의 기기 → 안드로이드 휴대폰 연결에서 앱 준비를 시작하세요. PC와 휴대폰을 같은 네트워크에 연결한 뒤 QR을 스캔하면 브라우저에서 앱을 내려받을 수 있습니다. 설치 화면의 안내에 따라 진행하세요.

  3. Wi-Fi 또는 USB로 연결

    처음에는 같은 네트워크의 Wi-Fi로 시작하면 간단합니다. Studio에 표시되는 6자리 번호를 휴대폰에 입력하세요. USB를 사용하려면 아래 연결 안내를 확인하세요.

  4. 원하는 버튼 설정

    Studio 미리보기에서 버튼을 선택하고 앱 실행·단축키·파일·폴더·URL 열기·매크로 등의 동작을 지정하세요. 저장하고 보드에 적용하면 연결된 휴대폰 화면에도 반영됩니다.

Wi-Fi와 USB, 어떤 연결을 쓰면 좋을까요?

Wi-Fi · 먼저 시작하기

PC와 휴대폰이 같은 로컬 네트워크에 있으면 사용할 수 있습니다. 유심이나 통신요금제는 필요하지 않습니다. 저장된 연결 정보로 다시 접속할 수 있습니다.

USB · 무선 연결이 어려울 때

앱 설치 후 USB AOA로 연결하면 같은 Wi-Fi 없이 사용할 수 있습니다. 데이터 케이블과 휴대폰의 액세서리 허용이 필요하며, Windows에서 별도의 UsbDk 드라이버 설치가 필요할 수 있습니다. 일반 사용에 USB 디버깅은 필요하지 않습니다.

구형 기기에서 USB 연결이 잘되지 않으면 먼저 Wi-Fi로 확인해 보세요. 일부 태블릿은 앱 업데이트 후 케이블을 뺐다가 다시 연결해야 합니다. 연결 문제 해결 →

오래된 스마트폰 활용, 자주 묻는 질문

유심 없는 공기계도 사용할 수 있나요?

네. Wi-Fi나 USB로 PC와 연결하므로 유심·전화번호·통신요금제가 필요하지 않습니다.

제조사 업데이트 지원이 끝난 태블릿도 되나요?

Android 5.0 이상에서 앱을 설치하고 실행할 수 있다면 활용할 수 있습니다. 기기별 USB 호환성은 다를 수 있으며, 먼저 Wi-Fi 연결로 확인하면 좋습니다.

스트림덱 같은 무료 단축키 패널로 쓸 수 있나요?

앱 실행, 단축키, 매크로와 미디어 조작을 터치 버튼에 배치할 수 있습니다. 전용 키패드 대신 이미 가진 휴대폰·태블릿으로 PC 컨트롤 패널을 구성해 보세요.

PC가 꺼져 있어도 사용할 수 있나요?

바로함의 버튼 화면과 위젯은 실행 중인 PC의 Studio와 연결해 사용합니다. PC가 종료되거나 완전히 절전 상태가 되면 정상적인 연결과 조작을 계속할 수 없습니다.

인터넷 없이도 사용할 수 있나요?

앱 설치와 필요한 준비를 마친 뒤에는 USB 또는 통신 가능한 로컬 네트워크로 연결할 수 있습니다. 로컬 앱 실행·단축키에는 인터넷이 필요하지 않지만, 웹사이트·뉴스·날씨 등 온라인 기능은 인터넷 연결이 필요합니다.

휴대폰이 없어도 시작할 수 있나요?

네. PC의 가상 바로함 창을 마우스로 사용하거나 작은 터치 모니터·보조 모니터에 배치할 수 있습니다. 가상 바로함 안내 →
