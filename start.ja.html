01. WindowsにStudioをインストール

  1. ダウンロード： 公式Windowsインストーラー。Windows 10 1809以降またはWindows 11のx64環境が必要です。
  2. 実行して利用規約とプライバシー通知を確認します。既定のインストール先： %LOCALAPPDATA%\Programs\DeskDeck.
  3. Microsoft WebView2がない場合はセットアップ中にダウンロードするため、インターネット接続が必要です。
  4. Baroham Studioを開きます。他の機器なしで仮想画面から始められます。

開発中の無料ソフトウェアです。使用前に規約を確認してください。 利用規約 · 保証と責任

Windowsに「不明な発行元」の警告が出ることがあります。 この版にはAuthenticode署名がありません。公式リポジトリ、ファイル名、公開SHA-256を確認してください。セキュリティソフトや組織の制限を無効にせず、ブロックされた場合は管理者に相談してください。

通常のインストールには管理者権限は不要です。自動起動はStudioの一般設定で変更できます。

02. 仮想Barohamを使う

  1. Studioの一般設定で、機器未接続時の仮想Barohamを有効にします。
  2. 別ウィンドウのボタンをクリックするか、タッチモニターでタップします。
  3. 好きなモニターへ移動し、端をドラッグしてサイズを変更します。位置とサイズは保存されます。
  4. 最後に接続した機器のサイズに合わせる設定も選べます。

小型タッチモニターや余った画面を操作パネルにできます。新しい機器やスマートフォンアプリは不要です。

03. Android携帯電話を接続

古いAndroid携帯電話・タブレットを再利用 →

Android 5.0以降に対応します。まず電話とPCを同じ信頼できるLANに接続します。相互通信できれば、有線PCとWi-Fi電話でも利用できます。

アプリを準備

  1. Studioの「機器」メニューからAndroid接続ガイドを開き、アプリがインストール済みか選びます。
  2. 必要なら電話でStudioのQRコードを読み取り、ブラウザーでAPKをダウンロードします。
  3. Androidの確認画面で、そのブラウザーからの不明なアプリのインストールを許可します。後で許可を取り消せます。組織のインストール規定を回避しないでください。
  4. 電話でBarohamを開き、Studioでインストール完了の手順へ進みます。

Wi-Fiで接続

  1. Studioと電話アプリの両方でWi-Fiを選びます。
  2. PCを探し、Studioに表示された初回6桁コードを入力します。
  3. ボタン画面が出れば接続完了です。次回以降は保存済みペアリング情報で再接続します。

USBで接続

  1. 電話のロックを解除し、USBデータケーブルでPCに接続します。
  2. 電話アプリでUSBタブ、StudioでUSBケーブルを選びます。
  3. 必要に応じてガイドに従いUsbDkを別途インストールします。この任意のシステムドライバーには管理者承認が必要で、同梱も自動インストールもされません。
  4. 電話でUSBアクセサリ要求を許可します。USB AOAにはWi-Fi用の6桁コードは不要です。

通常のWi-Fi・AOA接続にUSBデバッグは不要です。AOAの対応状況は電話、ケーブル、PCのUSB環境に依存します。登録機器は1台ずつ自動再接続します。更新後「PCに接続中」のままならケーブルを抜き差ししてください。一部の古いタブレットでは必要です。

アプリ更新と画面設定

ボタン画面下中央の小さな歯車をタップします。明るさ、待機時間、ヘルプ、バージョン、更新を設定できます。更新では接続先Studioのアプリパッケージを確認し、ブラウザーのインストール案内を開きます。全画面ウィジェットからはボタン画面へ戻って設定を開きます。

04. ESP32ボードを接続

現在の対応ボードは JC3248W535です。このファームウェアはすべてのESP32画面には対応しません。

  1. USBデータケーブルでボードをPCへ接続します。
  2. Studioの「機器」からESP32接続ガイドを開き、JC3248W535を選びます。
  3. 新しいボードでは、Baroham導入前に既存ファームウェアをバックアップするか選びます。ボードとポートを確認し、書き込み中はケーブルを抜かないでください。
  4. USBでボタン画面と入力を確認します。
  5. 無線利用時はUSB接続中にWi-Fiを設定します。以後は同一LANでUSBデータ接続なしに動作しますが、電源は必要です。

フラッシュ全体のバックアップにはWi-Fiパスワードが含まれる場合があります。公開Issueやサポートメールに添付しないでください。同梱ファームウェア：0.8.2。

05. ボタンとマクロを作る

  1. Studioのプレビューでボタンを選びます。
  2. 名前と動作を選びます。インストール済みアプリ、アプリのパス、ショートカット、システム情報などを指定します。
  3. 内蔵または独自のアイコンを選びます。
  4. 保存して機器に適用します。接続した電話や仮想画面にも反映されます。

ボタン配置と画像の追加

プレビューの右クリックでコピー、切り取り、貼り付け、左右への挿入、削除、リセットができます。挿入・削除は後続ボタンをページ間で移動し、Mは最後に残ります。リセットは位置を保って内容を消します。

動作一覧で「空白ボタン」を選び、アイコンライブラリから画像を読み込みます。縦横比は保たれ、タップしても動作しません。「+」枠はStudio編集画面を開きます。画像変更後は保存して適用してください。

ボタン組み合わせマクロ

ボタン動作、ショートカット、文字列、待機を順に組み合わせます。入力の種類と値を指定し、選択した手順の下へ追加します。待機は秒単位で小数も可。Tab・Enterはショートカット入力で、文字列には入力後Enterを送る選択肢もあります。

マクロ編集の確定は変更をボタン編集へ戻します。永続保存にはStudioで保存・適用します。実行中のマクロは下部の状態欄またはトレイから停止できます。

マクロ文字列はWindowsアカウントで暗号化保存されますが、実行時は実際の入力として送られます。安全なウィンドウで試してください。パスワードのチェックは一覧を隠すもので、パスワード管理機能ではありません。

ページ管理

ページを追加、リセット、並べ替えできます。大きい画面では通常ボタンが保存順で再配置され、ページ数が減る場合があります。Mメディアページは最後です。画面端またはスワイプでページを巡回します。

06. 全画面ウィジェット

時計、ネコ、メディアなどの内蔵ウィジェットを選びます。管理画面で有効化・ドラッグ並べ替えを行い、手動または待機時間後に表示します。

左右端のタップやスワイプで切り替えます。時計・ネコはタップでボタンへ戻り、操作型ウィジェットには戻る操作があります。縦横比を保ち、余白は背景に合わせ、小さな定期移動で位置固定を減らします。

Androidの待機輝度は電話アプリで設定します。Windowsモニターの消灯とPC全体のスリープは異なります。PCが完全にスリープすると通常通信は続行できません。

07. 接続トラブルを解決

PCの検出やQRページが動きません。

同一LANで、ゲストWi-Fiが機器間通信を遮断していないか確認します。Studioの案内に従い必要な範囲のみファイアウォールを許可し、ダウンロード中は導入ガイドを開いておきます。

USBで充電できますが接続しません。

充電専用ではなくデータケーブルを使います。AndroidではアプリのUSBモード、アクセサリ承認、AOAドライバーを、ESP32ではポートと対応ボード型番を確認します。

ウィンドウを閉じるとStudioは終了しますか？

Studioはトレイで動作を続けることがあります。完全終了にはトレイの「終了」、設定を再表示するにはトレイアイコンを使います。

Androidでアプリをインストールできません。

StudioのQR案内からブラウザーでAPKを再ダウンロードしてください。署名証明書が異なるアプリは上書き更新できません。旧アプリ削除前に必要なペアリングや設定を確認し、組織の制限は管理者に相談してください。

外部ウィジェットが突然停止しました。

Studio 0.9.41では、外部ウィジェットで実行エラーや安全規則違反が検出されると、そのウィジェットが自動的に停止することがあります。Studioの全画面ウィジェット → ウィジェット管理で停止理由を確認し、原因を解消してから手動で再度有効にしてください。通常のインターネット接続の切断やサーバーエラーは、自動停止の理由にはなりません。

問題を報告

お問い合わせは GitHubのIssue またはメール deskdeck.app@gmail.comへ。バージョン、接続方法、再現手順、エラー文を記載し、パスワード、個人設定、機器全体のバックアップは送らないでください。

08. 終了とアンインストール

トレイからStudioを終了し、Windowsのインストール済みアプリからBarohamを削除します。設定が残る場所： %LOCALAPPDATA%\DeskDeck。このフォルダーや独自バックアップを削除する前に必要な内容を保存してください。

UsbDkは別プログラムです。不要になれば別途アンインストールできます。AndroidのアプリデータやESP32のペアリング情報は各機器の手順に従って削除します。

Androidタッチパッドを使う

Studioの「機器 → タッチパッド」で有効にし、電話のボタン画面下部のアイコンをタップします。USB・Wi-Fiで移動、左右クリック、ドラッグ、スクロールができます。ゲーム保護や管理者アプリでは入力が制限される場合があります。
